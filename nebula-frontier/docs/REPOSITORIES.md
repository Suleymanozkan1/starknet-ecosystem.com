# Repositories

All ten mandated repositories were cloned into `tools/reference-repos/` (`pnpm repos:clone`), inspected (README, package.json, source, examples, tests), and their licenses checked. Reference clones are git-ignored and never bundled; production code uses the published npm packages. Raw notes: [`research/REFERENCE_REPOS_NOTES.md`](research/REFERENCE_REPOS_NOTES.md).

## License compliance
- No source files or assets from any reference repository are copied into the product. Patterns are re-implemented.
- MIT/Apache-2.0/ISC dependencies are used under their terms; notices ship with the npm packages.
- The Metaplex license applies to the package as a dependency; review it before a mainnet launch.
